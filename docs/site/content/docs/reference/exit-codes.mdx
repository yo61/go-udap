---
title: Exit codes
description: What go-udap's exit codes mean
---

| Code | Meaning |
|---|---|
| `0` | Success |
| `1` | Operation failure — device not found, transport error, timeout, MethodError reply |
| `2` | Usage error — bad MAC, unknown parameter name, invalid parameter value, unknown or invalid flag, conflicting flags, wrong number of arguments, unknown subcommand, unknown interface name |

Each subcommand's reference page lists the specific conditions that
produce code `1` vs `2` for that command.
